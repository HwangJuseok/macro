# 수강신청 빈자리 감지기 (매크로)

이 프로젝트는 파이썬(Python)을 활용한 자동화 제어(PyAutoGUI), 이미지 처리(OpenCV), GUI 프로그래밍(Tkinter), 그리고 멀티스레딩 기술을 학습하기 위한 목적으로 개발된 개인 토이 프로젝트입니다.
